# Udacity Portfolio Site

This project was created as part of the **Udacity Front-End Web Developer program**.

The goal of the project is to build a responsive personal portfolio website that showcases projects, skills, and personal information using modern web development practices.

## Project Overview

This portfolio website presents different projects with images, descriptions, and links.
It demonstrates the use of HTML and CSS to build a structured and responsive layout.

## Features

* Responsive portfolio layout
* Project showcase section
* Clean UI structure
* Image-based project cards
* Simple and modern design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run the Project

1. Clone the repository

```
git clone https://github.com/ali-yaqoup/udacity-portfolio-site.git
```

2. Open the project folder
3. Open `index.html` in your browser
