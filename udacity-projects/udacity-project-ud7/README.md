# Udacity Project UD7

This project was created as part of the **Udacity learning program** to practice building web applications using modern frontend development techniques.

## Project Overview

The project demonstrates how to build a structured web application while applying core web development concepts such as layout design, styling, and interactive functionality.

## Features

* Structured web application layout
* Interactive UI elements
* Clean and readable code structure
* Responsive design principles

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run the Project

1. Clone the repository

```
git clone https://github.com/ali-yaqoup/udacity-project-ud7.git
```

2. Open the project folder
3. Open `index.html` in your browser
