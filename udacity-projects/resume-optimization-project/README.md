# Resume Optimization Project

This project was developed as part of the **Udacity learning program**.

## Project Overview

The goal of this project is to build an interactive resume webpage that displays personal information, education, work experience, and skills in a structured and visually organized format.

It demonstrates how JavaScript can dynamically generate resume content on a webpage.

## Features

* Dynamic resume layout
* Sections for skills, education, and experience
* Structured data rendering using JavaScript
* Clean and organized UI

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run the Project

1. Clone the repository

```
git clone https://github.com/ali-yaqoup/resume-optimization-project.git
```

2. Open the project folder
3. Open `index.html` in your browser
