# Udacity Website Project

This project was developed as part of the **Udacity Nanodegree program**.
The goal of the project is to practice building a simple and structured website using core web development technologies.

## Features

* Clean and simple webpage structure
* Responsive layout
* Basic styling with CSS
* Semantic HTML structure

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the repository
2. Open the `index.html` file in your browser
